# GPA & CGPA Calculator

A single-page calculator for tracking university grades, built with plain HTML, CSS, and JavaScript.

## Features
- Splash screen with animated intro
- Profile setup (name, university, department, level, target CGPA)
- Multiple semesters, multiple courses per semester
- Live GPA / CGPA calculation
- Course validation based on a configurable marking scheme
- Data persisted in `localStorage`

## Tech
- HTML5
- CSS (custom properties, flex/grid, `prefers-color-scheme`)
- Vanilla JavaScript (no frameworks, no build step)

## Run locally
Just open `index.html` in a browser.
